# AI Fluency Lab

This repository contains a collection of hands-on AI and LLM experiments organized as labs and tasks. It covers foundational prompting, agent patterns, reasoning strategies, robustness testing, and retrieval-based systems.

## Overview

The workspace is divided into:

- [lab-1](lab-1/) through [lab-8](lab-8/): structured learning labs exploring different AI application patterns.
- [Task](Task/): task-based exercises that apply the same concepts to practical scenarios.

The focus is on understanding how AI systems behave when using:

- plain LLM chat
- rule-based workflows
- tool-using agents
- chain-of-thought and self-consistency reasoning
- retrieval and document search
- robustness and validation techniques

This repo is intended as a learning and experimentation space for AI application development.
